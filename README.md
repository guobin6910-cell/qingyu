# 青嶼戰記

手機優先戰術 SRPG。

線上：https://guobin6910-cell.github.io/qingyu/

## 特色
- 連續手繪六角戰場＋高細節 Q 版全身立繪（致敬經典台製 SRPG 呈現）
- 六角戰術與地形
- 三大職階樹、功勳晉升、分支鎖定、必殺
- 隱藏招募與遺跡、林青川 Rank-4
- 存檔鍵 qingyu-v1

npm run build
